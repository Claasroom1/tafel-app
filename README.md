# Tafel-App

Digitale Tafel für Smartboards und Tablets – läuft im Browser, lässt sich als App installieren und funktioniert danach auch offline.

**App öffnen:** über die Adresse dieser Seite (GitHub Pages), z. B. `https://BENUTZERNAME.github.io/tafel-app/`

## Auf einem Board oder PC installieren

**Windows (Microsoft Edge):** Adresse öffnen → oben rechts **⋯** → **Apps** → **„Diese Website als App installieren“**. Danach gibt es die Tafel-App im Startmenü und auf Wunsch auf dem Desktop – mit eigenem Fenster, ohne Adressleiste.

**Android-Board / Tablet (Chrome):** Adresse öffnen → **⋮** → **„App installieren“** bzw. „Zum Startbildschirm hinzufügen“.

Die App einmal mit Internet öffnen, dann ist sie vollständig gespeichert und startet auch ohne Netz.

## Wo bleiben die Daten?

- Die App hat **keinen Server und kein Konto**. Tafeln, Notizen und Namenslisten werden **nicht ins Internet** übertragen.
- **Windows:** Beim ersten Start einen Ablageordner wählen (z. B. im IServ- oder OneDrive-Ordner). Dort liegen die Tafeln als Dateien.
- **Android:** Die Tafeln liegen im Speicher der App auf dem Gerät. Bitte regelmäßig **📁 Tafeln → „💾 Sicherung exportieren“**.
- Einzige Ausnahme: Beim **Einfügen eines PDFs** wird der PDF-Leser (PDF.js) von `cdnjs.cloudflare.com` nachgeladen.

Alles Weitere steht in der [Anleitung](Anleitung.md).
